# SPRITE SHEET PROMPTS — same recipe as Calnyxys

Paste one into Gemini. Save the result as `refs/<name>.png` (all lowercase).
Then in the game: press **P** → **RENAME** → type the name.

The last paragraph of every prompt is the part that keeps them all matching.
Don't change it.
